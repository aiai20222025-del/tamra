탐라노인복지센터 랜딩페이지
================================

구성 파일
- index.html : 랜딩페이지 본문
- style.css : 반응형 디자인 및 스타일
- script.js : 모바일 메뉴 동작
- assets/ : 기관 로고, 첫 화면 배경, 센터장 사진, 활동사진, 첨부 폰트 파일

FTP 업로드 방법
1. 압축 파일을 PC에서 해제합니다.
2. FTP 프로그램(FileZilla 등)으로 웹호스팅 계정에 접속합니다.
3. 호스팅 업체에서 안내한 웹 루트 폴더(일반적으로 public_html, www 또는 htdocs)에
   index.html, style.css, script.js와 assets 폴더를 함께 업로드합니다.
4. 도메인으로 접속해 PC와 모바일에서 확인합니다.

수정 전 확인할 사항
- 현재 요청에서 제공된 주소와 밴드 링크를 반영했습니다.
- 전화번호는 제공되지 않아 임의로 만들지 않았습니다. index.html의 상담 영역에
  실제 기관 전화번호를 추가한 뒤 게시하세요.
- 활동사진 설명은 이미지 내용을 바탕으로 작성한 예시 문구입니다.
- 첨부된 Griun_Yeeun-Rg.ttf 폰트를 assets 폴더에 포함하고 로컬 적용했습니다.
  별도 웹폰트 연결 없이 사용할 수 있습니다.
- 스크롤 시 섹션 페이드업, 좌우 슬라이드, 카드 줌인 및 순차 등장 애니메이션과 상단 진행 표시를 적용했습니다.
  사용자가 기기에서 동작 줄이기를 설정한 경우 애니메이션은 자동으로 최소화됩니다.
- FTP 업로드 전에 호스팅 업체의 웹 루트 경로와 HTTPS 설정을 확인하세요.
